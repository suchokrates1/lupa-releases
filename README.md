# Lupa

Powiększenie ekranu dla Windows od Vest Media. Dok na krawędzi ekranu, pełny ekran albo soczewka. Lupa idzie za myszą, fokusem i tekstem, który piszesz.

To repozytorium służy tylko do wydań. **Instalator pobierzesz z [ostatniego wydania](https://github.com/suchokrates1/lupa-releases/releases/latest).**

- Windows 10 2004 x64 i nowsze
- Instalacja dla bieżącego konta, bez uprawnień administratora
- Lupa sama sprawdza, czy jest nowa wersja

## Skróty

| Skrót | Co robi |
| --- | --- |
| Ctrl + Shift + L | pokazuje i chowa lupę |
| Ctrl + Shift + S | otwiera ustawienia |
| Ctrl + Shift + kółko myszy | zmienia powiększenie |
| Ctrl + Shift + ← / → | zmienia tryb |

Pełna lista i ustawienia są w panelu Lupy.

## Licencja

Lupy możesz używać za darmo. Nie wolno jej zmieniać ani sprzedawać.
